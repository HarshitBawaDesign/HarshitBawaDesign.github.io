# hobi — Harshit Bawa

Portfolio of Harshit Bawa (hobi): animator, illustrator and interactive media designer in Toronto.

Static site with no build step and no dependencies. Open `index.html`, or serve the folder with any static host (GitHub Pages, Netlify).

- `js/projects.js`: every project, its text, credits and media. Edit this file to add or change work.
- `css/site.css`: styles, following the hobi Contact & About page design.
- `js/site.js`: the animations and interactions.
- `media/`: compressed images and videos.
- `tools/`: scripts used to build `index.html` (inlines the hobi face SVG) and to compress media.
